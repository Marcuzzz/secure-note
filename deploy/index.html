SecureNote

Encrypted notes & password manager for Android. Master password, biometric unlock, built-in password generator.

Install for Android All releases

Requirements

  • Android 8.0 (API 26) or newer
  • You'll need to allow installs from unknown sources — see below.

First-time install

Since this is side-loaded (not from Google Play), Android will ask you to allow install from your browser or file manager the first time. Open Settings → Apps → Special app access → Install unknown apps and enable it for the app you're downloading with.

Tap the button above on your Android device, then open the downloaded SecureNote-release.apk.

Security

  • Master password derives a 256-bit key (PBKDF2-HMAC-SHA256, 200k iterations).
  • The whole database is encrypted at rest with SQLCipher (AES-256).
  • Optional biometric unlock — key is wrapped by an Android Keystore-backed AES-GCM key.
  • Screenshots and recents previews are blocked (FLAG_SECURE).
  • Auto-locks when backgrounded. Cloud backup disabled.

There is no password recovery. Lose the master password → lose the notes.

Updates

New releases are published to the Releases page. The link above always points to the latest.
